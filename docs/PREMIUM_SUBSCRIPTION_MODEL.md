# Premium Subscription Model - Launch Strategy

## Overview

**Launch Strategy**: Everyone gets premium for one month free at launch

**Premium Model**: Similar to X's Blue Star program - premium users get enhanced features and access

**Visual Indicator**: Blue star badge (like X's verification checkmark)

---

## Core Premium Features

### 1. **Canopi Access** ⭐ (Already Planned)
- **Free**: Limited to canopi under capacity
- **Premium**: Access to ANY canopi, even those over capacity
- **Throttling**: Free users see "Canopi Full" message, premium users can always join

### 2. **Attachment Size** ⭐ (Already Planned)
- **Free**: Standard attachment size (e.g., 5MB per file, 3 files per message)
- **Premium**: Larger attachments (e.g., 25MB per file, 10 files per message)
- **Throttling**: Free users hit upload limits, premium users get expanded limits

### 3. **Blue Star Badge** ⭐ (Already Planned)
- **Free**: No badge
- **Premium**: Blue star badge next to username
- **Visual**: Similar to X's verification checkmark, but blue star icon

---

## Additional Premium Features (Throttling Opportunities)

### 4. **Message Rate Limits**
- **Free**: 
  - 50 messages per day
  - 5 messages per minute (rate limit)
- **Premium**: 
  - Unlimited messages per day
  - 20 messages per minute (higher rate limit)
- **Throttling**: Free users see "Rate limit reached" after hitting daily/minute limits

### 5. **Reaction Limits**
- **Free**: 
  - 20 reactions per day
  - 1 reaction per message
- **Premium**:

- **Throttling**: Free users see "Reaction limit reached" message

### 6. **Bookmark Limits**

## Throttling Implementation Patterns

### Pattern 1: Hard Limits (Access Denied)
```typescript
if (!isPremium && currentCount >= freeLimit) {
  showUpgradeMessage("Upgrade to Premium for unlimited access");
  return false;
}
```

### Pattern 2: Soft Limits (Graceful Degradation)
```typescript
if (!isPremium && currentCount >= freeLimit) {
  showWarning("You've reached your free limit. Upgrade for more.");
  // Still allow but show warning
}
```

### Pattern 3: Feature Locking (UI Disabled)
```typescript
if (!isPremium) {
  element.disabled = true;
  element.classList.add('premium-locked');
  showTooltip("Premium feature - upgrade to unlock");
}
```

### Pattern 4: Rate Limiting (Temporary Block)
```typescript
if (!isPremium && rateLimitExceeded) {
  const waitTime = calculateWaitTime();
  showMessage(`Rate limit reached. Try again in ${waitTime} seconds.`);
  return false;
}
```

## User Experience Considerations

### Upgrade Prompts
- **Non-intrusive**: Show upgrade prompts at natural breakpoints (e.g., after hitting limit)
- **Value-focused**: Explain what they get with premium
- **Easy upgrade**: One-click upgrade flow

### Free Tier Value
- **Generous limits**: Free tier should be usable for casual users
- **Clear boundaries**: Users should understand what's free vs premium
- **No bait-and-switch**: Don't hide limits until users hit them

### Premium Value Proposition
- **Clear benefits**: Users should immediately see premium value
- **Blue star visibility**: Premium badge should be prominent
- **Feature discovery**: Help users discover premium features
