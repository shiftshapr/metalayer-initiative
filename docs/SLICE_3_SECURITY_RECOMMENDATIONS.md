## Risk Assessment

**Severity**: Medium-High  
**Likelihood**: Medium (depends on user input validation)  
**Impact**: XSS (Cross-Site Scripting) vulnerability

### Current State

- `convertUrlsToLinks()` function converts URLs to `<a>` tags but **does not escape HTML**
- `UnifiedMessageRenderer.generateMessageHTML()` uses `convertUrlsToLinks()` without sanitization
- `ensureMessageContent()` only ensures string type, doesn't sanitize
- No HTML escaping utility found in `src/utils/`

### Example Vulnerability

If a user submits a message with:
```html
<script>alert('XSS')</script>
```

This would be executed when inserted via `innerHTML`.

---

## Recommendations

### Immediate Actions

1. **Add HTML Escaping Utility**
   - Create `src/utils/HtmlSanitizer.ts` with `escapeHtml()` function
   - Use DOM API: `document.createTextNode(text).textContent` or manual escaping

2. **Sanitize Before innerHTML**
   - Escape user content before passing to `convertUrlsToLinks()`
   - Or escape after URL conversion but before innerHTML assignment

3. **Consider DOMPurify**
   - For more complex sanitization needs
   - Allows safe HTML while preventing XSS

### Implementation Options

#### Option 1: Simple HTML Escaping (Recommended for immediate fix)
```typescript
// src/utils/HtmlSanitizer.ts
export function escapeHtml(text: string): string {
  const div = document.createElement('div');
  div.textContent = text;
  return div.innerHTML;
}

// Usage in convertUrlsToLinks:
function convertUrlsToLinks(text: string | undefined): string {
  if (!text) return '';
  const escaped = escapeHtml(text);
  const urlRegex = /(https?:\/\/[^\s]+)/g;
  return escaped.replace(urlRegex, '<a href="$1" target="_blank" rel="noopener noreferrer">$1</a>');
}
```

#### Option 2: Use DOMPurify (For production)
```bash
npm install dompurify
npm install --save-dev @types/dompurify
```

```typescript
import DOMPurify from 'dompurify';

// Sanitize before innerHTML
const sanitized = DOMPurify.sanitize(html, { 
  ALLOWED_TAGS: ['a', 'b', 'i', 'em', 'strong', 'p', 'br'],
  ALLOWED_ATTR: ['href', 'target', 'rel']
});
```
