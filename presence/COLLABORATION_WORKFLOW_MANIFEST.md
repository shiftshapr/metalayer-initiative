# Default Collaboration Workflow Manifest
**Project:** Canopi  
**Version:** 1.0  
**Last Updated:** 2025-01-24

## Workflow Definition
This manifest defines the standard agent collaboration workflow for Canopi project tasks.

## Agent Sequence
1. **PM (Project Manager)** - Architecture analysis and requirements validation
2. **SD (Senior Developer)** - Implementation and code review
3. **TEST (Test Engineer)** - Test case creation and validation
4. **RED (Red Hat)** - Security penetration testing
5. **WHITE (White Hat)** - Security integrity and privacy audit
6. **PURPLE (Purple Hat)** - Adversarial defense testing
7. **BLINDSPOT** - Edge case identification
8. **BLUE (Blue Hat)** - Final audit and oversight
9. **DEVOPS** - Deployment and infrastructure verification
10. **ETHICS** - Compliance and ethical review

## Agent Responsibilities

### PM (Project Manager)
- Analyze task requirements
- Validate architecture alignment
- Identify dependencies
- Create implementation plan

### SD (Senior Developer)
- Implement features
- Code review
- Best practices enforcement
- Performance optimization

### TEST (Test Engineer)
- Create test cases
- Execute tests
- Validate functionality
- Report test results

### RED (Red Hat)
- Security penetration testing
- Vulnerability assessment
- Exploit simulation
- Threat modeling

### WHITE (White Hat)
- Security integrity audit
- Privacy compliance
- Secure design review
- Cryptography validation

### PURPLE (Purple Hat)
- Adversarial testing
- Edge case simulation
- Attack-defense scenarios
- Resilience testing

### BLINDSPOT
- Identify missed edge cases
- Review assumptions
- Challenge implementation
- Suggest improvements

### BLUE (Blue Hat)
- Final audit
- Quality assurance
- Risk assessment
- Approval/rejection

### DEVOPS
- Deployment verification
- Infrastructure testing
- CI/CD validation
- Monitoring setup

### ETHICS
- Ethical compliance
- AI governance
- User privacy
- Transparency review

## Red-Line Audits
- **Security:** No hardcoded credentials, proper authentication
- **Privacy:** No unauthorized data collection
- **Performance:** No blocking operations, proper async handling
- **Accessibility:** WCAG compliance, keyboard navigation
- **Compatibility:** Cross-browser support, graceful degradation

## Blind-Spot Checks
- Race conditions
- Memory leaks
- Error handling
- Edge cases
- User experience
- Performance degradation

## Approval Criteria
- All agents must sign off
- No red-line violations
- All blind-spots addressed
- Tests passing
- Documentation complete
